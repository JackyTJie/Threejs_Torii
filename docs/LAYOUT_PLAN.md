## 1. 尺度与坐标约定

- **1 单位 = 1 m**。
- 底座 **32 × 32 m** 规整正方形纯色深灰平板；内容区 `x ∈ [-16, 16]`，`z ∈ [-16, 16]`。
- 坐标轴：**+X = 画面右**、**+Z = 画面前（镜头侧）**、**+Y = 上**。
  参道沿 Z 轴纵伸：**石阶底端在 +Z（近镜头）**，逐级抬升向 **−Z（深林）** 隐没。
- 相机注视点公式 `pos = target + (cos az·cos el, sin el, sin az·cos el) · r`
  ⇒ **正对参道的正向 = 方位角 90°**（相机位于 target 的 +Z 侧）。
  该方位下相机屏幕右向 = **+X**，屏幕左向 = **−X**。
  ⇒ **画面左（−X）= 山涧浅溪 + 陡坡**；**画面右（+X）= 山坡林地**（与参考图一致）。
- 默认机位：target `(0.3, 3.6, -0.9)`（前座鸟居中心略上），半径 24 m，方位 90°，俯仰 26°
  → 机位约 `(0.3, 14.2, 20.3)`，视线朝前下方。
  前景 = 最下段石阶 + 积水洼 + 溪口；中景 = 两座鸟居（焦点）；背景 = 隐没的上段参道与深林。
- 微缩展台感换算：32 m 内容区按 1:87（O 轨）折算约 **37 cm 见方**的手办展台。

## 2. 标高 LEVEL

| 名称 | y (m) | 说明 |
| --- | --- | --- |
| pad | 0.00 | 纯色深灰底座顶面 |
| pathBase | 0.16 | 石阶底端顶面（第 1 级踏面） |
| pathTop | 4.80 | 石阶顶端顶面（第 32 级踏面） |
| valleyFloor | 0.30 → 5.13 | 溪谷谷底（随 z 抬升，见下式） |
| streamBed | valleyFloor − 0.16 | 溪床（沟槽底） |
| waterSurface | valleyFloor − 0.05 | 水面（护岸顶净空 0.05 m） |
| pathLeftFoot | 谷底 → 参道 | 参道左侧坡脚（溪谷 → 石阶的过渡带） |
| pathShoulder | 参道 + 0.10 | 参道右路肩 |
| rightHillTop | 参道 + 2.40 | 右侧山坡林地顶（pad 边缘处） |
| leftRidgeTop | valleyFloor + 1.58 → 2.10 | 左侧山脊（溪谷外侧） |

### 参道连续坡面（地形与石阶共用的基准坡面）

```
pathRampY(z) = 0.16 + (11.60 - z) * 0.29        // z ≤ 11.60（含上段隐没部分）
             = 0.16                              // z > 11.60（底座前缘平台）
```

### 溪谷基准

```
valleyLevel(z) = 0.30 + (11.60 - z) * 0.185     // 谷底比参道缓，越往 -Z 谷越深、参道越高
waterY(z)      = valleyLevel(z) - 0.05
streamBedY(z)  = valleyLevel(z) - 0.16
```

前缘（z = 11.6）：谷底 0.30 / 水面 0.25 / 床 0.14，参道 0.33 → 参道与谷底几乎齐平（溪口浅滩）。
后缘（z = -14.5）：谷底 5.13 / 水面 5.08 / 床 4.97，参道 7.73 → 参道高出谷底 2.60 m（陡坡，露根系）。

### 地形连续函数（`js/assets/terrain.js` 实现，分区只用于放置判定，不产生硬接缝）

```
terrainHeight(x, z) =
    加权带宽平均( 左脊 / 左陡坡 / 溪谷 / 参道左坡脚 / 参道走廊 / 右路肩 / 右坡 )
  + 微起伏 fbm3(x, z)
  - 0.16 * streamMask(x, z)          // 溪床下切
  最终 clamp ≥ pad + 0.02
```

加权平均（不是取最大值）：带边界处用 smoothstep 羽化，保证相邻带共用同一顶点值 ⇒ 无台阶状接缝。

| 主带 | x 范围 | 标高 | 说明 |
| --- | --- | --- | --- |
| leftRidge 左脊林 | `x ≤ C(z) - 2.40` | valleyFloor + 1.58→2.10 | 溪谷外侧山体，樟/枫主干林 + 厚落叶层 + 青苔巨石 |

## 5. 参道石阶系统

- 32 级，**每级独立建模、独立 Mesh**（不合并、不实例化共享材质对象；共享几何可以，合并网格不行）。
- 第 k 级（k = 0 … 31）：
  - 前缘 `z = 11.60 - 0.50 k`，踏面覆盖 `z → z - 0.50`
  - 顶面 `y = 0.16 + 0.145 (k + 1)`
  - 立面（riser）高 0.145 m，从上一级顶面到本级顶面
  - 石板宽 2.70 m（`x ∈ [-1.05, 1.65]`），厚 0.145 m，**每级沿 X 再切成 2–3 块独立石板**（接缝、错位、磕碰）
- 石阶总坡降 4.64 / 16.00 = **0.29**；第 25 级前缘 z = −0.90（前座鸟居），第 30 级前缘 z = −3.40（后座鸟居）。
- 上段参道（z < −4.40）：不再做规整台阶，改为**石板铺装的坡道残段**，在 z ≈ −7 处被两侧树木围合遮蔽（"隐没于深林"）。
- 侧边泥土地：参道两侧各 0.35–0.90 m 宽的深色湿泥带，带碎石、落叶、凹凸肌理（`path-soil.js`）。

## 10. 光影、景深与描边方案

- **主光（唯一投影光源）**：方位 155°、俯仰 38°，色 `0xe8eef2`，强度 1.9 —— 雨后阴天从右后上方来的漫射主光。
- **半球光**：天空 `0xa8bcc8` / 地面 `0x3f4638`，强度 0.75 —— 抬暗部层次。
- **轮廓光（rim）**：方位 335°（主光对侧）、俯仰 16°，色 `0xcfe0d2`，强度 0.60 —— 给鸟居与树冠边缘一层冷边光。
- **环境光**：`0x3f4a44`，强度 0.22。
- **雾**：`FogExp2`，`0x8fa39a`，密度 0.016 —— 纵深空气感，后段参道自然隐没。
- **阴影**：正交视锥按「底座正方形 + 场景高度」反算；`shadowSceneTop 14`、`shadowSceneBottom -1.6`、`shadowDistance 52`、贴图 4096、PCFSoft、bias −0.0004 / normalBias 0.02。
- **景深**：焦点跟随**鸟居对中心** `DOF_FOCUS (0.30, 5.60, -2.15)`，不跟随相机注视点（缩放不会把焦点带走）；前景（底座前缘石阶）轻微虚化、远景（深林）中等虚化。
- **描边**：反向壳体 + 深度边缘双路，同一距离曲线。`thickness 0.011`、`maxThickness 0.03`、屏幕线宽 1.6 px（≤14 m）→ 0.7 px（≥60 m），远处只减淡不淡出。
- **不描边**：底座、水面、叶片薄片、薄雾面片、积水洼、发光面片、泥土/地形（见 `NO_OUTLINE_PREFIXES`）。
- **色调**：冷调低饱和（`warmth` 由秋暖 0.055 降到 −0.02，`saturation 1.02`），保留鸟居朱红饱和度。

## 13. 视角与交互范围硬性约束

```
CAMERA = {
  fov 46, near 0.08, far 420,
  target (0.30, 3.60, -0.90), radius 24,
  radiusMin 3.2, radiusMax 46,          // 无极缩放
  azimuthDeg 90, azimuthMin 60, azimuthMax 120,   // ±30°，禁止转到背面
  elevationDeg 26, elevationMin -10, elevationMax 45,
  panEnabled false                       // 禁用自由平移
}
```

- **缩放耦合的注视点推移**（保证「最近看清台阶纹理 / 最远全景 + 底座完整可见」）：
  `t = (r - radiusMin) / (radiusMax - radiusMin)`
  `targetZ = lerp(9.50, -1.20, t)`，`targetY = groundHeight(target) + 1.20`，`target.x` 固定 0.30（±3.0 上限）。
- **地面穿透保护**：对俯仰做二分，保证 `camera.y ≥ groundHeight(cam.x, cam.z) + 0.30`；不满足则收紧俯仰下限。
- **可视范围**：`radiusMax 46` + `fov 46`（16:9 时水平半角 ≈37°）覆盖整个 32 m 底座四角；
  因此建模覆盖 = 整个内容区，**底座外缘（|x| 或 |z| > 15.9）与背面一律不建模**，坡地外露面用裙壁（展台断崖）收边。
- 无 UI、无水印、无文字标注、无控件；`index.html` body 只有 `canvas`。

## 15. 放置校验规则（`js/layout.js` 与 `tools/scene-audit.mjs` 必须实现）

| 规则 | 内容 |
| --- | --- |
| R1 底座边界 | 资产包围盒必须落在 `±(PAD.half + 0.05)`；`scene-assembly` 另按 `CONTENT_HALF + 0.6` 硬抛错 |
| R2 参道走廊净空 | 非参道类资产的包围盒不得进入 `x ∈ [-1.05, 1.65]` 且 `z ∈ [-8.0, 12.2]` 的走廊体（鸟居/石阶/路肩/积水洼/湿石块例外，白名单声明） |
| R3 溪谷净空 | 非水系资产的最低点不得低于该处溪床 + 0.02，且不得横穿溪床中心线（`stream*` 前缀资产豁免） |
| R4 鸟居净空 | 任何植被/道具不得进入两柱之间 `x ∈ [-1.50, 2.10]`、`z ∈ [-4.20, -0.10]`、`y < 柱基 + 4.38` 的鸟居体积 |
| R5 悬空 / 埋入 | `box.min.y > groundHeight + 0.36` ⇒ 悬空报错；`box.max.y < groundHeight - 0.02` ⇒ 完全埋入报错。`support` 可为数值、`{top}`、`{host:{x,y,z}}`、`{overhead:true}` |
| R6 宿主包含 | 依附型资产（苔藓斑块、积水洼、藤蔓）必须落在宿主包围盒内（容差 0.06） |
| R7 树冠重叠 | 相邻乔木冠幅重叠率 ≤ 45%（允许交叠成林，不允许完全重合） |

多实例资产通过 `root.userData.samples` 提交逐实例包围盒供审计。
